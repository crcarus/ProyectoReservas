# ProyectoReservas
Proyecto que busca habilitar reserva de horarios para toma de clases, con la opción de pagar por medio de transferencia y tarjeta. Opción de reseva de hora, correo confirmación y opción de guardar en google calendar, cancelar hora hasta ciertas horas antes, poder configurar rangos horarios por mes en curso, entre otras funcionalidades
